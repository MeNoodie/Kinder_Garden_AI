# Security Policy

## Supported versions

Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Please do not open a public GitHub issue for a potential security vulnerability. Instead, contact the repository maintainer privately through the GitHub profile with a description, reproduction steps, impact, and any suggested mitigation.

You will receive an acknowledgement as soon as possible. Please allow time for investigation and a fix before disclosing the vulnerability publicly.
